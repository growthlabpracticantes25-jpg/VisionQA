# Guía de Identidad Visual - VisionQA

## Base corporativa

El proyecto VisionQA utilizará como referencia el Manual de Identidad Corporativa de IOT Technologies.

## Colores institucionales

- Azul institucional: #1D7EAE
- Negro institucional: #231F20
- Blanco: #FFFFFF
- Gris claro: #F5F5F5

## Tipografía

Las tipografías permitidas son:

- Open Sans
- Roboto

## Aplicación en VisionQA

La interfaz, documentación, diagramas y presentaciones del proyecto deberán utilizar colores institucionales, diseño limpio, fondos blancos o claros y texto legible.

## Elementos visuales

- Encabezados en azul institucional.
- Texto principal en negro institucional.
- Botones y líneas divisorias en azul.
- Fondos claros.
- Evitar colores ajenos al manual, excepto para indicadores:
  - Verde: APTO
  - Rojo: NO APTO
  - Amarillo: REVISIÓN

## Aplicaciones

Esta identidad se aplicará en:

- Interfaz Streamlit
- Diagramas de arquitectura
- Documentación técnica
- README
- Presentación final
- Póster
- Reportes
